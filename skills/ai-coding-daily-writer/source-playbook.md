# AI Coding Daily Source Playbook

## Scope

Cover only changes that materially affect software development:

- coding models
- coding agents
- AI IDEs and editor plugins
- CLI coding tools
- benchmark or evaluation updates
- release notes, pricing, enterprise controls
- workflow patterns that change how teams ship code

Ignore generic AI news unless it clearly changes coding workflows.

## Source Priority

Use sources in this order:

1. Official product blog or docs
2. Official changelog or release notes
3. Official GitHub repo releases or commits
4. Official social announcement with concrete details
5. Reputable secondary analysis

## Writing Checklist

Before publishing, verify:

- Every time-sensitive claim has an exact date
- Official links are included
- The article separates facts from inference
- Marketing language is rewritten into engineering impact
- Each item answers "why should an engineer care?"

## Daily Brief Structure

Use this section order:

1. TL;DR
2. What changed today
3. Why it matters
4. What to test
5. Watchlist
6. Sources

## Topic Selection Rule

Prefer 3 to 5 strong items over 10 weak items.

Good items:

- a new coding model release
- an agent workflow that changes how code is planned or executed
- a pricing or governance change that affects team adoption
- a benchmark result with practical implications

Weak items:

- vague teasers without docs
- generic AI news unrelated to coding
- copied social hype without reproducible details
