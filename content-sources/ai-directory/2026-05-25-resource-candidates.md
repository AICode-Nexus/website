# AI Resource Directory Candidate Sources

## Collection Rules

- Foreign official and high-quality AI websites are the default baseline.
- Chinese resources remain useful, but they live mostly in `中文社区与导航`.
- `trendStatus: hot` means the resource is a current high-attention entry in this collection window, not a permanent market ranking.
- `trendStatus: rising` means the resource is moving into more teams' evaluation sets and should be watched.
- Healthcare, legal, and finance resources are collected as entry points only; they are not professional advice.

## Deferred Sources

- Deep vertical resources that require domain expert validation before inclusion.
- News-only sites that may be useful for monitoring but are not stable learning or work resources.
- Tool directories with unclear ownership, affiliate-heavy pages, or poor maintenance signals.

## Rejected Sources

- Thin SEO listicles.
- Tool pages without stable official ownership.
- Medical, legal, or financial pages that imply advice without clear professional review or source boundaries.

## Verification Notes

- The first implementation pass records source URLs and category decisions, then relies on `npm run check:ia`, `npm run check:content`, and `npm run build` for site-level validation.
- External websites can change after the collection window. Refresh `reviewedAt`, `sourceWindowEnd`, and `trendWindowEnd` when re-checking hot or rising resources.
- Hot markers are intentionally sparse so category pages remain useful after short-term trends cool down.
