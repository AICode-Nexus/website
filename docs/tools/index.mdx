# AI 编程工具

这页不是“产品百科”，而是工具分流器。目标只有一个：把你尽快送进正确的 `quick-start`，而不是把平台、控制面、执行栈、终端入口和 IDE 工作台混成一锅。

## 现在先做什么

- 想先收一份官网、官方文档和仓库名单：去 [AI 资源导航](/docs/ai-directory)。
- 想最快跑通终端主入口：去 [Claude Code 快速开始](/docs/tools/terminal-agents/claude-code/quick-start)。
- 想在平台里跑任务到 PR：去 [GitHub Copilot 快速开始](/docs/tools/platforms/github-copilot/quick-start)。
- 想推进长链路任务：去 [OpenAI Codex 快速开始](/docs/tools/execution-stacks/openai-codex/quick-start)。
- 想把 IDE 当主入口：去 [Cursor 快速开始](/docs/tools/ide-first/cursor/quick-start)。
- 想统一本地与后台 agent：去 [VS Code Agents 快速开始](/docs/tools/control-planes/vscode-agents/quick-start)。
- 想先看真实执行闭环：去 [Codex Refactor with Verification 案例](/docs/case-studies/codex-refactor-with-verification)。
