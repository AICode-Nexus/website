# AI 编程工具

这一层不再只按“哪个产品最热”来堆页面，而是先回答一个工程问题：你现在最需要的是平台、控制面、执行栈、终端入口，还是 IDE-first 主入口。

## 先决定你在选什么

- 平台型：重点是 issue、PR、review、Jira 和工作系统闭环。
- 控制面：重点是本地 agent、background agents 和 editor 内的统一调度。
- 执行栈：重点是审批、worktree、并行任务和长链路执行。
- 终端 Agent：重点是 repo pairing、命令验证和规则文件。
- IDE-First：重点是编辑体验、rules、记忆和日常高频交互。
