# Cursor

Cursor 是打磨很深的 IDE-first 入口：把编辑体验、rules、background agents 和上下文管理组合成主开发环境。

## 角色定位

IDE-first 主入口，强项是高频交互式编辑与逐步扩展到 background agents。

## 最适合谁

- 默认长期在 IDE 中工作、重视编辑体验的个人工程师或小团队。
- 想把 rules、context 和 background agents 收进一个日常主入口的人。
- 需要较强交互式编辑体验，同时又想有 agent 能力的组织。

## 默认工作方式

- 这个入口真正高价值的地方是：IDE-first 主入口，强项是高频交互式编辑与逐步扩展到 background agents。
- 如果它不能回流到 repo 证据、验证命令和人工 review，它就只是在制造另一层会话噪音。
- 最稳的使用方式通常不是“让它承担全部职责”，而是和平台、框架或终端验证形成分层。
