# Cursor 最佳实践

## 优先固化什么

- 固化规则文件和目录边界。
- 固化“先计划、再改动、再验证”的 IDE 节奏。
- 固化最适合 IDE 入口的小步任务类型。

## 什么时候最值

- 你长期在 IDE 内完成日常开发。
- 多数任务是局部实现、维护或补测试。
- 你愿意维护规则和验证回路。
