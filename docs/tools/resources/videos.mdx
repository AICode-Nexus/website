# AI Code 全部视频

这个页面只保留近 90 天、{teachingVideoCatalogSync.intervalLabel} 自动同步一次的公开视频条目。只有当前时间窗里确实形成多集系列时，才会额外开放课程目录，避免把伪聚合结果塞进主链路。

<TeachingVideoSyncSummary generatedAt={teachingVideoCatalog.generatedAt} showPill />

## 什么时候优先看全部视频

- 你已经知道自己要找的是具体视频条目，而不是课程系列。
- 你需要按平台、语言、工具、主题和难度快速筛选公开视频。
- 你想先看单条内容，再根据页面是否出现课程入口决定要不要按系列继续学。

## 当前目录规则

- 只展示 `windowStart` 到 `windowEnd` 时间窗内的公开视频。
- 同一语言的重复镜像会做 canonical 去重，并保留 `alternateUrls`。
- 页面运行时不做任何外部抓取，所有分类、打标、排序都在同步脚本阶段完成。
- 只有在当前时间窗确实形成多集系列时，才保留课程目录入口。

## 同步入口

```bash
npm run sync:teaching-videos
npm run check:teaching-videos
npm run build
```

自动同步策略：**{teachingVideoCatalogSync.description}**

## 什么时候切到课程目录

- 如果页面已经显示课程目录入口，且你通过视频条目确认某位创作者或某个系列值得系统性看完，再切到 [课程目录](/docs/resources/courses)。
- 如果你看完素材后想把经验回流到长期知识结构，回到 [AI 编程工具](/docs/tools) 或 [AI 工作流](/docs/workflows)。
