# AI Code 课程目录

课程目录是视频结果的派生聚合视图。只有当前时间窗里确实形成多集系列时，这里才会显示正式课程聚合；否则页面会直接提示你回到 [全部视频](/docs/resources/videos)。

## 课程视图适合什么时候用

- 当前页面已经开放课程目录，而且你不只是想找一条视频，而是想按系列内容连续学习。
- 你希望按创作者、课程主题和长期学习路径浏览，而不是逐条筛素材。
- 你已经通过 [全部视频](/docs/resources/videos) 锁定了几个值得系统追的课程方向。

## 当前聚合规则

- 课程视图只在存在真实多集系列时开放，不再把“1 条视频 = 1 门课程”的结果当成稳定聚合。
- 课程视图来自当前筛选命中的视频结果，不再额外混入无关课程。
- 如果某门课程当前没有命中视频条目，它就不会出现在这页里。
- 课程目录仍然只承接学习材料，不替代独立的 [视频资源](/docs/resources/videos) 入口或 [AI 编程工具](/docs/tools) 的长期知识结构。

## 什么时候切回全部视频

- 如果你已经锁定课程，但需要回到单条视频细看发布时间、语言或具体主题，切回 [全部视频](/docs/resources/videos)。
- 如果你已经学完一轮，想把经验回流到长期知识结构，继续去 [AI 工作流](/docs/workflows) 或 [内容索引](/docs/content-index)。
