# 视频资源说明

`视频资源` tab 现在默认直接进入 [全部视频](/docs/resources/videos)。这个页面不再作为主入口，只保留 `全部视频` 和 `课程目录` 的分工说明。

这里默认拆成两类视图：

- [全部视频](/docs/resources/videos)：按可直接播放的视频条目筛选和浏览。
- [课程目录](/docs/resources/courses)：把当前筛选命中的视频实时聚合成课程视图。

## 两类视图怎么分

- 如果你已经知道自己要找的是具体视频条目，先去 [全部视频](/docs/resources/videos)。
- 如果你更想按系列内容、课程作者和连续学习路径浏览，先去 [课程目录](/docs/resources/courses)。
- 这两个页面都只承接学习材料，不负责替代 [AI 编程工具](/docs/tools) 或 [AI 工作流](/docs/workflows) 的长期知识结构。

## 使用原则

- 要找具体素材，先从这里进入。
- 要找官网、官方文档和 GitHub 仓库目录，去 [AI 资源导航](/docs/ai-directory)。
- 要理解工具定位、规则边界和治理方式，回到 [AI 编程工具](/docs/tools)。
- 课程目录是视频结果的聚合视图，不再插在视频列表中间。

## 什么时候回长期知识方向

- 如果你要把视频里的经验落回默认入口、执行栈和 IDE 选择，回到 [AI 编程工具](/docs/tools)。
- 如果你要把视频里的操作方式收成稳定交付链，回到 [AI 工作流](/docs/workflows)。
- 如果你要把素材里的 review、验证与门禁要求沉淀成规则，回到 [规范评估与治理](/docs/standards)。
