# 主流工具观察名单

## 目的

这份名单不是“最好用工具榜”，而是知识治理名单。

进入名单，意味着：

- 站点需要持续复核它的官方变化
- 与它相关的对比文和专题文要按月回看
- 它的变化可能影响默认工具栈或规则文件体系

## 当前名单

- GitHub Copilot
- VS Code Agents
- OpenAI Codex
- Claude Code
- Gemini CLI
- Cursor
- Windsurf

## 暂不进入长期名单的情况

- 只有单点功能发布，没有改变工作方式
- 还没有稳定官方文档或官方仓库信号
- 对主流规则文件、工作流或架构没有持续影响

## 月度复核问题

1. 这个工具的默认入口或定位是否发生变化？
2. 它是否引入新的规则文件、记忆、MCP 或 agent 类型？
3. 它是否改变了 issue、PR、review、Jira 或 CI 的连接方式？
4. 它是否值得让长期文档重写或重排？
