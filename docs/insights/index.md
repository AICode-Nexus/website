# 趋势观察

## 这一类内容解决什么问题

趋势页的职责不是追热点，而是把热点压缩成长期判断，帮助团队回答：

- 现在最值得观察的主线变化是什么
- 哪些变化还只是短期信号
- 哪些变化已经值得回流到长期 docs

## 当前入口

- [2026 年 3 月 AI Coding 的四个主线变化](/docs/tools/insights/agentic-coding-patterns)
- [2026 年 3 月月度简报](/docs/tools/insights/monthly-brief-2026-03)
- [Daily Brief](/blog)

## 使用原则

- 先在 Daily Brief 里发现变化
- 再在月度简报里判断价值
- 最后才回流到长期知识文档

## 哪些内容适合进趋势页

- 能形成阶段性判断的变化
- 已经连续出现、不再是一次性热点的信号
- 能转化为工作流、规范或架构决策的内容

## 哪些内容不该直接进趋势页

- 只有热度、没有工程行动价值的更新
- 尚未确认真伪的单条传闻
- 只能作为当天快讯阅读的零散变动
