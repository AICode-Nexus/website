# 2026 年 3 月月度简报

## 本期最重要的变化

- GitHub、VS Code、OpenAI 都在强化 Agent 工作台能力
- 记忆、rules、hook 和 sandbox 开始变成主话题
- 平台级集成和长任务执行都在加速成熟

## 为什么重要

月度视角能帮助你区分“当天很热”和“本月真正应该记住”的变化。

## 对个人工程师的影响

- 应该优先搭个人稳定栈
- 应该开始记录任务类型和效率变化
- 应该学会按任务选平台，而不是固定只用一种入口

## 对团队的影响

- 团队会越来越关注治理和成本边界
- 低风险任务委派会成为更现实的切入点
- review 和测试流程会被重新强调

## 接下来观察什么

- Cursor / Windsurf / Cline 的差异是否继续扩大
- issue -> agent -> PR 流程是否更成熟
- 平台级 memory 是否进入企业治理议题
