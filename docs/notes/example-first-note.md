# 示例：如何让 AI 输出可执行的技术文档

## 背景
- 问题：AI 内容容易空泛
- 场景：团队知识沉淀需要可执行文档

## 结论
- 先约束输出结构，再要内容
- 强制要求步骤与边界
- 最终版本必须人工校验

## 详细步骤
1. 指定受众和场景
2. 指定固定 Markdown 模板
3. 要求给出最小示例
4. 人工改写成团队可执行版本

## 示例
```text
请输出面向初级工程师的 Markdown 文档，主题：CI 失败排查。
必须包含：背景、结论、步骤、常见错误、风险与边界。
```

## 风险与边界
- AI 可能引用过时信息
- 涉及生产权限的操作必须补充审批流程
