# 按岗位进入 AI+ 知识库

这个页面不是"岗位百科"，而是角色分流器。目标只有一个：根据你的日常工作角色，把你尽快送进最相关的 AI coding 场景、方法和可复用资产。

## 为什么需要按岗位进入

- 不同岗位的 AI coding 场景差异很大：产品要验证原型，前端要调样式，后端要写迁移，测试要生成用例。
- 通用教程无法覆盖每个角色的具体痛点和交付物。
- 按岗位组织内容，可以让你更快找到"我这个角色该怎么用 AI"。

## 选择你的岗位

- [产品经理](/docs/roles/product) - AI 辅助需求分析、原型验证和交付跟踪
- [设计师](/docs/roles/design) - AI 辅助设计系统、组件生成和可访问性验证
- [前端工程师](/docs/roles/frontend) - 从设计输入、组件实现、样式系统到验证交付的前端 AI 工作台
- [后端工程师](/docs/roles/backend) - AI 辅助 API 契约、数据库迁移、服务集成和上线回归
- [测试工程师](/docs/roles/qa) - AI 辅助测试用例生成、自动化脚本和缺陷分析
- [运维工程师](/docs/roles/devops) - AI 辅助配置管理、监控告警和故障排查
- [数据分析师](/docs/roles/data-analysis) - AI 辅助数据清洗、可视化和报表生成

## 每个岗位页面包含什么

1. **典型 AI coding 场景** - 这个岗位最常遇到的 3-5 个 AI 协作场景
2. **推荐方法与工作流** - 针对这个岗位的工具选型和工作流建议
3. **可复用资产** - 规则文件、prompt 模板、验证脚本等
4. **跨团队交付物** - 这个岗位如何与其他角色协作
5. **内部链接** - 回到通用教程、工具教程、工作流教程的跳转

- 如果你已经知道自己的岗位，直接进入对应页面。
- 如果你是个人开发者，可能需要同时看前端、后端、测试三个角色。
- 如果你想先跑通用主线，回到 [30 分钟上手](/docs/start/30-minute-quick-start)。
