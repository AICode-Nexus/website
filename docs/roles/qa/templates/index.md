# QA 训练包模板

QA 机制页最怕只停在“应该补证据”这种原则层。更稳的做法是直接复制模板，把测试计划、缺陷复现、命令记录和 handoff 都写成固定结构。

![QA 训练包图板](/img/roles/qa/qa-training-pack-board.svg)

## 先用哪份

| 场景 | 先复制什么 |
| --- | --- |
| 测试任务 kickoff | [测试计划 Brief 模板](/docs/roles/qa/templates/test-plan-brief) |
| bug 已经出现，需要固定复现路径 | [缺陷复现与回归模板](/docs/roles/qa/templates/bug-repro-and-regression) |
| 自动化和人工验证一起收口 | [命令与证据模板](/docs/roles/qa/templates/commands-and-evidence) |
| 需要交给开发、产品或下一个测试 owner | [QA Handoff 模板](/docs/roles/qa/templates/handoff-template) |
