# 命令与证据模板

```md
# Commands

- [ ] unit / api / integration:
- [ ] e2e:
- [ ] coverage:

## Environment

- branch:
- browser / device:
- test data:

## Evidence

- screenshot:
- recording:
- logs:
```

## 使用提醒

- 命令、环境和证据必须在同一处
- 如果没跑某项，要写原因
