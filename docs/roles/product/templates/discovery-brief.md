# 发现与调研 Brief 模板

```md
# {调研主题}

## 1. 要回答的问题
- 这次调研想回答哪一个决策问题
- 不回答哪些问题

## 2. 已知前提
- 已经确定的业务背景
- 现有流程 / 系统边界
- 已确认的限制条件

## 3. 假设
- 假设 A：
- 假设 B：
- 这些假设为什么重要

## 4. 调研范围
- 用户侧
- 设计 / 体验侧
- 技术可行性侧
- 成本 / 依赖侧

## 5. 证据来源
- 用户反馈 / 访谈
- 竞品截图 / 链接
- 官方文档 / API 说明
- 仓库或现有系统事实

## 6. 输出要求
- 最终要给出的建议
- 需要的对比表或截图
- 需要回链的资料

## 7. 开放问题
- 还缺哪些信息
- 需要谁补充
- 截止时间
```

## 使用提醒

- 先写“要回答的问题”，再去查资料，否则调研会无限发散。
- 证据来源最好分成用户、竞品、官方、repo 事实四类，避免只引用单一来源。
