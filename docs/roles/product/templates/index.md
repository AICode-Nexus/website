# 产品训练包模板

产品侧最容易散掉的，不是观点，而是产物结构。把“需求真相”“调研结论”“验证结果”“交付 handoff”收成固定模板后，AI 才不会每次都从空白文档重新发明格式。

![产品训练包图板](/img/roles/product/product-training-pack-board.svg)

## 先复制哪份

| 场景 | 先复制什么 |
| --- | --- |
| 需求刚启动，需要把背景和验收写稳 | [PRD 大纲模板](/docs/roles/product/templates/prd-outline) |
| 还在做问题澄清、竞品或技术调研 | [发现与调研 Brief 模板](/docs/roles/product/templates/discovery-brief) |
| 需要对原型、方案或关键假设做验证 | [原型验证模板](/docs/roles/product/templates/prototype-validation) |
| 需要交给设计、研发、测试或发布 owner | [Handoff 与验收模板](/docs/roles/product/templates/handoff-and-acceptance) |

## 配套页面

| 模板组 | 配套页面 |
| --- | --- |
| PRD 与 discovery | [产品经理](/docs/roles/product)、[规则与规范文档](/docs/roles/product/rules-and-instruction-files) |
| 能力与调研方式 | [Skills 与 MCP](/docs/roles/product/skills-and-mcp) |
| 入口与任务形状 | [工具匹配与选型](/docs/roles/product/tool-fit-and-selection) |

## 默认复制顺序

1. 先从 [发现与调研 Brief 模板](/docs/roles/product/templates/discovery-brief) 或 [PRD 大纲模板](/docs/roles/product/templates/prd-outline) 起步。
2. 需要验证方案时，再补 [原型验证模板](/docs/roles/product/templates/prototype-validation)。
3. 进入跨团队推进或验收阶段时，用 [Handoff 与验收模板](/docs/roles/product/templates/handoff-and-acceptance) 收口。
