# Handoff 与验收模板

```md
# {需求 / 发布项}

## 1. 本次交付摘要
- 做了什么
- 不做什么
- 当前状态

## 2. 必看链接
- PRD / spec
- 设计稿 / 原型
- 技术方案 / issue
- 测试或验证结论

## 3. 验收清单
- 主路径
- 边界情况
- 范围外确认

## 4. 风险与待确认项
- 已知风险
- 未覆盖项
- 需要谁确认

## 5. 上线与回看
- 计划上线窗口
- 上线后看哪些指标
- 出现异常时如何止损
```

## 使用提醒

- 交付摘要要先写边界，再写细节。
- 风险不要只写“有风险”，要写清触发条件和观察指标。
