# 训练包模板

前端专题已经把“输入包”“证据包”“规则模板包”讲清了，下一步就该把它们变成真的可复制模板。这一组页只做一件事：给你一套最小可用的前端训练包，让团队不用每次从空白文档重新发明格式。

## 建议怎么用

| 你现在处于哪一步 | 先复制哪个模板 | 为什么 |
| --- | --- | --- |
| 设计稿刚进仓库，还没开始拆页面 | [页面输入包模板](/docs/roles/frontend/templates/page-input-pack) | 先把 Figma、token、状态和截图位收齐 |
| 任务启动前，需要把范围和验收写清楚 | [任务 Brief 模板](/docs/roles/frontend/templates/task-brief) | 先锁边界，再开做 |
| 改动已经开始，需要固定验证证据位置 | [命令与证据模板](/docs/roles/frontend/templates/commands-and-evidence) | 防止命令、截图、录屏散落在聊天里 |
| 要给 reviewer 或下一个接手人交付 | [PR / Handoff 模板](/docs/roles/frontend/templates/pr-handoff) | 让交付说明足够快读、可继续推进 |
| 需要单独记录未覆盖风险和下一步 | [Risks / Next 模板](/docs/roles/frontend/templates/risks-and-next) | 让“还没覆盖什么”被显式写下来 |

## 默认复制顺序

1. 先复制 [页面输入包模板](/docs/roles/frontend/templates/page-input-pack) 或 [任务 Brief 模板](/docs/roles/frontend/templates/task-brief)。
2. 任务开始后，把 [命令与证据模板](/docs/roles/frontend/templates/commands-and-evidence) 一起建好。
3. 进入 review 或 handoff 前，再补 [PR / Handoff 模板](/docs/roles/frontend/templates/pr-handoff) 和 [Risks / Next 模板](/docs/roles/frontend/templates/risks-and-next)。
