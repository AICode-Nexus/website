# 报告 Handoff 模板

```md
# {报告主题}

## 1. 一句话结论
- 最重要的发现

## 2. 关键图表 / 表格
- 图表 1
- 图表 2
- 图表 3

## 3. 方法与口径
- 数据源
- 时间窗口
- 指标定义

## 4. 限制条件
- 数据缺口
- 口径限制
- 不应过度解释的地方

## 5. 建议动作
- 建议给谁
- 建议何时做
- 需要补哪些验证
```

## 使用提醒

- `一句话结论` 要和图表能互相印证。
- `限制条件` 不能埋在脚注里，必须显式写给读者。
