# 数据分析训练包模板

数据分析任务最怕“图做出来了，但没人知道怎么复现”。把分析 brief、质量检查、命令记录和报告 handoff 写成模板后，结论、脚本和限制条件才能保持同步。

![数据分析训练包图板](/img/roles/data-analysis/data-analysis-training-pack-board.svg)

## 先复制哪份

| 场景 | 先复制什么 |
| --- | --- |
| 分析刚启动，需要锁定问题和口径 | [分析 Brief 模板](/docs/roles/data-analysis/templates/analysis-brief) |
| 还没开始写脚本，先要固定质量检查 | [数据质量检查模板](/docs/roles/data-analysis/templates/data-quality-checklist) |
| 脚本、notebook 和导出需要可复现记录 | [命令与复现模板](/docs/roles/data-analysis/templates/commands-and-repro) |
| 要把结果交给产品、运营或管理层 | [报告 Handoff 模板](/docs/roles/data-analysis/templates/report-handoff) |

## 配套页面

| 模板组 | 配套页面 |
| --- | --- |
| 分析定义与质量边界 | [数据分析师](/docs/roles/data-analysis)、[规则与规范文档](/docs/roles/data-analysis/rules-and-instruction-files) |
| 能力与工具编排 | [Skills 与 MCP](/docs/roles/data-analysis/skills-and-mcp) |
| 入口选择与执行顺序 | [工具匹配与选型](/docs/roles/data-analysis/tool-fit-and-selection) |

## 默认复制顺序

1. 先用 [分析 Brief 模板](/docs/roles/data-analysis/templates/analysis-brief) 和 [数据质量检查模板](/docs/roles/data-analysis/templates/data-quality-checklist) 锁定口径。
2. 编写脚本或 notebook 时，把 [命令与复现模板](/docs/roles/data-analysis/templates/commands-and-repro) 一起建好。
3. 输出结论前，用 [报告 Handoff 模板](/docs/roles/data-analysis/templates/report-handoff) 收口。
