# 分析 Brief 模板

```md
# {分析主题}

## 1. 要回答的问题
- 业务问题
- 决策背景
- 不在本次回答范围内的内容

## 2. 指标与口径
- 指标定义
- 时间窗口
- 维度与过滤条件

## 3. 数据源
- 表 / 文件 / API
- 权限和新鲜度
- 已知缺口

## 4. 输出要求
- 图表 / 表格 / 报告
- 受众
- 截止时间

## 5. 风险与假设
- 口径风险
- 数据质量风险
- 依赖外部同学补充的信息
```

## 使用提醒

- `指标与口径` 不要等到脚本阶段才补。
- `数据源` 最少要写名字、新鲜度和已知缺口三项。
