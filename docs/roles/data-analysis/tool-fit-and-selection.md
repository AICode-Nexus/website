# 工具匹配与选型

| 任务形状 | 更适合的入口 |
| --- | --- |
| SQL、脚本和数据校验 | 终端入口 |
| notebook、可视化和探索式分析 | IDE / 分析环境 |
| 表格与报表输出 | 表格 / 导出类能力 |
| 指标协作和平台跟踪 | 平台型入口 |

## 一个判断原则

先问当前任务核心是“探索”“验证”“汇报”还是“交付”。不同核心，对入口的要求完全不同。

## 典型入口组合

如果任务是探索式分析，优先 IDE 或 notebook 环境；如果任务是质量校验或 SQL 复核，优先终端；如果任务已经进入正式报表或表格交付，再切到更适合结构化输出和导出的能力。顺序对了，分析结果才容易复现。

## 常见误选

- 本来只是做一次性探索，却过早搭复杂平台流程。
- 本来需要严格质量校验，却直接跳到图表层。
- 本来需要多人协作审阅，却把结果留在本地脚本或截图里。
