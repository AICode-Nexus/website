# 工具匹配与选型

| 任务形状 | 更适合的入口 |
| --- | --- |
| SQL、脚本和数据校验 | 终端入口 |
| notebook、可视化和探索式分析 | IDE / 分析环境 |
| 表格与报表输出 | 表格 / 导出类能力 |
| 指标协作和平台跟踪 | 平台型入口 |

## 一个判断原则

先问当前任务核心是“探索”“验证”“汇报”还是“交付”。不同核心，对入口的要求完全不同。
