# 工具匹配与选型

| 任务形状 | 更适合的入口 |
| --- | --- |
| 设计稿还原与组件生成 | Figma + 代码入口 |
| 原型或交互验证 | 浏览器类入口 |
| 设计系统文档化 | 长文档和结构化输出入口 |
| 与开发协作跟踪 | 平台型入口 |

## 设计任务的一个基本判断

先问自己：现在缺的是设计上下文、真实页面、规范文档，还是跨团队同步。答案不同，入口就不同。
