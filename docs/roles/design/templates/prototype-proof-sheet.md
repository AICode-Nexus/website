# 原型验证与证据模板

```md
# {原型 / 页面名}

## 1. 验证目标
- 想验证什么
- 哪些问题暂时不验证

## 2. 验证路径
- 主路径
- 失败路径
- 键盘 / 可访问性路径

## 3. 证据要求
- 录屏
- 截图
- 浏览器或原型链接

## 4. 观察结果
- 通过点
- 卡点
- 与设计预期不一致的地方

## 5. 下一步
- 继续推进 / 需要重画 / 需要联调
- owner
```

## 使用提醒

- 录屏和截图至少保留一种，不要只留文字。
- `观察结果` 最好按路径写，方便 QA 和前端继续复核。
