# 每日更新工作流

## 背景

Daily Brief 是站点时效层，必须比普通文档更强调日期与来源准确性。

## 标准流程

1. 先确认日期范围
2. 再搜集官方来源
3. 最后写 Daily Brief 和精选摘要

## 固定结构

- TL;DR
- What changed today
- Why it matters
- What to test
- Watchlist
- Sources

## 内部要求

- 所有最新信息必须有精确日期
- 优先官方来源
- 热点文章要能回流到 docs 专题
