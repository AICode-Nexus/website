# 发布到 GitHub Pages

## 一次性配置

1. 配置仓库与 Pages
2. 选择 GitHub Actions 作为发布方式
3. 确认默认分支和 Pages 设置

## 自动发布

- push 到 `main` 或 `development`
- Actions 构建并上传 `build`
- Pages 自动部署
