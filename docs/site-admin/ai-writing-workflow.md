# AI 写作流程

## 目标

用统一模板和固定结构生成可编辑的文档初稿。

## 流程

1. 明确受众和场景
2. 固定输出结构
3. 强制要求步骤与边界
4. 人工审核后发布

## 推荐结构

- 背景
- 结论先行
- 核心概念
- 推荐做法
- 常见错误
- 延伸阅读
