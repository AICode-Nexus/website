# AI 编程工具

## 这一类内容解决什么问题

- 用统一框架比较平台、终端 agent、AI IDE 和开放式入口
- 识别当前真正主流、值得持续追踪的工具
- 给组织建立“主入口 + 备用入口 + 观察名单”的组合
- 避免把工具热度误当成长期知识结构

## 当前主流分层

- 平台型：GitHub Copilot
- 执行栈型：OpenAI Codex
- 终端 agent：Claude Code、Gemini CLI
- AI IDE：Cursor、Windsurf、VS Code Agent
- 开放式入口：Cline / Continue

## 推荐做法

- 先选 1 个默认入口承担 60% 到 80% 的日常任务
- 再选 1 个补位入口承担长任务、后台执行或特定生态
- 把进入观察名单的工具按月复核，而不是每周改默认栈
