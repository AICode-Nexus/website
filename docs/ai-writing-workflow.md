# AI 写作流程

## 标准流程

1. 明确问题：场景、受众、约束
2. 让 AI 产出初稿（要求 Markdown）
3. 人工审阅：核验事实、补充组织上下文
4. 以统一模板沉淀到 `docs/notes/`
5. 提交到 Git，自动发布

## 推荐提示词

```text
你是资深工程师，请按 Markdown 输出：

# 标题
## 背景
## 结论（先给可执行结论）
## 详细步骤
## 示例
## 风险与边界
## 参考资料

要求：
- 结论可直接执行
- 示例最小可复现
- 避免空话
```
