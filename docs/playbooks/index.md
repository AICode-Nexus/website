# Playbooks

## 这一类内容解决什么问题

Playbook 不是一级骨架，而是“AI 工作流”支柱下最可执行的一层。它用来回答：

- 具体该怎么做
- 先做什么后做什么
- 哪些步骤需要验证和人工接管

## 当前入口

- [个人工程师栈搭建](/docs/playbooks/personal-engineer-stack-setup)

## 什么时候该看 Playbook

- 你已经知道为什么要这么做
- 你现在需要可直接照着走的动作
- 你希望把同类任务固定成模板

## 一个好的 Playbook 至少要包含什么

- 适用场景
- 前置准备
- 执行步骤
- 验收方式
- 不要做什么

## 推荐使用方式

先用 Playbook 试跑真实任务，再把失败点回流到 contract、rules 和 review 清单，而不是把 Playbook 当作一次性教程。
