# 模型 API 与平台

这一类资源解决的是“我该先把哪些模型 API 和 provider 入口固定下来”。这里不做详细对比，而是帮你把官网、Docs 和统一 provider 入口先收藏好，避免每次临时再找。

## 这类资源怎么用

- 先把主 provider 的官方 Docs 收下来，建立默认接入基线。
- 再根据是否需要开源模型、多模型路由或性能型推理平台补第二层入口。
- 不要把聚合入口当成唯一事实来源，核心能力仍以官方平台为准。

## 建议进入顺序

1. 先看 `OpenAI / Anthropic / Gemini` 这类主 provider 官方入口。
2. 如果你要补开源模型和多模型平台，再看 `Hugging Face / Together / Replicate / Fireworks`。
3. 如果你只是想快速做横向试验，再把 `OpenRouter` 当精选补充，而不是平台基线；需要落地路径时，继续看 [OpenRouter 接入与路由方案](/docs/tools/openrouter-routing-playbook)。
