# 行业专题

这一类资源收教育、法律、金融、医疗、电商、媒体、制造、客服等行业 AI 资源。它的目标是提供可信入口，不提供专业意见。

## 这类资源怎么用

- 优先看官方、机构或行业内高可信资源。
- 对医疗、法律、金融类资源，必须额外确认合规、责任和人类审核边界。
- 不把产品宣传语当作行业最佳实践，真正落地前要回到具体组织流程验证。
