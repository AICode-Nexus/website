# 中文社区与精选导航

这一类不是官方产品文档，而是“中文世界里值得长期收藏的社区入口”。它的目标是补充中文导航、中文 prompt 方法资源和社区精选仓库，减少你每次都从社交媒体碎片里重新找线索。

## 这类资源适合什么时候看

- 你已经有官方 Docs 基线，但需要中文入口、中文方法资源或导航站辅助。
- 你想快速扫一遍中文圈正在讨论什么，再决定要不要回官方资料深挖。
- 你需要给团队整理一份更适合中文读者的入口集合。
