# Agent Skills 与插件生态

这一页收的是公开可访问的 Agent Skills 标准、运行入口实现文档、插件市场和方法论型 skill pack。它不是本机已安装 skill 清单，也不发布本地缓存路径；目录只保留读者能自己打开、验证和收藏的公开入口。

这里的 `skill` 不是 Claude、Codex 或 VS Code 下面的子功能分类，而是面向 AI agent / harness 的能力单元。Codex、Claude Code、VS Code 这些条目只说明“这个运行入口如何读取、调用、共享或分发 skills”，不是把 skill 归属到某一个 AI 服务名下。

## 类型速览

| 类型 | 解决什么问题 | 先看什么 |
| --- | --- | --- |
| `skill-standard` | 理解 `SKILL.md`、脚本、参考资料和资源如何组成可移植能力包 | Agent Skills standard |
| `skill-runtime-docs` | 看不同 AI 运行入口如何发现、加载、共享和执行同一种 skill 能力单元 | Codex Skills、Claude Code Skills、VS Code Agent Skills |
| `plugin-marketplace` | 找可安装的能力包、插件目录或团队分发方式 | Codex Plugins、Superpowers Marketplace |
| `methodology-pack` | 把一组 skills 组合成稳定工作方法 | Superpowers |
| `mcp-bundle` | 把 MCP server、app connector 和 skill 放进同一个安装单元 | Codex Plugins、社区 marketplace |

## 更新规则

这个目录采用“半自动候选 + 人工入库”：

- `content-sources/skill-plugins/watchlist.json` 记录公开来源、候选类型、仓库入口和推荐理由。
- `npm run monitor:skill-plugins` 定期生成 dated candidate report，只标记 `new`、`changed`、`watch`。
- 候选报告不会自动改 `src/data/aiDirectory.js`；只有确认来源可信、适用场景清楚、维护信号稳定后，才进入公开目录。
- 普通博客榜单、社媒热帖或无法追溯到官方文档 / GitHub 仓库 / 可信 marketplace 的条目，只能进入观察，不作为推荐。
