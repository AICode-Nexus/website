# AI 资源导航

这不是“AI 全网大全”，而是一个面向 `AI coding / agents / LLM application` 的精选目录。目标是把优秀官网、官方文档、开源仓库和课程入口放到一个可维护的结构里，减少你每次都从搜索引擎重新找入口的成本。

## 这页怎么用

- 先按你当前缺的入口形状分，再进入具体分类页，而不是先刷热门榜单。
- 如果你在找产品、IDE、CLI 或执行型 agent，先去 `AI 编码工具与执行型 Agent`。
- 如果你在找 framework、RAG/agent runtime、LLMOps 或模型平台，直接切到对应分类，不要和学习资源混看。
- 如果你更需要中文入口和长期收藏站，再去 `中文社区与精选导航`。

## 这轮补了什么

- 把原来 4 个手写表格页升级成统一数据源驱动的目录。
- 在原有 `编码工具 / Agent`、`框架 / 编排`、`Eval / LLMOps`、`课程 / Cookbook` 之外，新增了 `模型 API 与平台`、`MCP 与协议生态`、`中文社区与精选导航` 三类。
- 继续保留 [Microsoft AI Agents for Beginners](https://github.com/microsoft/ai-agents-for-beginners) 作为学习资源类的官方课程仓库样板。
