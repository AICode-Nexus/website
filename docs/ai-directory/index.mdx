# AI 资源导航

这不是“AI 全网大全”，而是一个面向全行业 AI 学习与工作的精选目录。目标是把国外优秀官网、官方文档、开源仓库、课程、Cookbook、行业资源和岗位工作入口放到一个可维护的结构里，减少你每次都从搜索引擎重新找入口的成本。

## 这页怎么用

- 先按岗位、行业或技术任务分，再进入具体分类页，而不是先刷热门榜单。
- 如果你在找模型平台、官方文档、Cookbook 或 API，先去 `基础与官方平台`。
- 如果你在找 AI coding、agent、MCP 或 LLM 应用开发，直接切到对应技术分类。
- 如果你在找产品、设计、运营、销售、数据、办公或行业资源，按工作场景进入。
- 如果你更需要中文入口和长期收藏站，再去 `中文社区与导航`。

## 这轮补了什么

- 把原来的 AI coding / agents 目录升级为全行业 AI 资源库。
- 分类扩展为 `基础与官方平台`、`研发与 AI Coding`、`Agent 与应用开发`、`产品与设计`、`运营与市场`、`销售与商务`、`数据与分析`、`企业效率与办公`、`行业专题`、`中文社区与导航`。
- 资源条目开始支持 `最新热门`、`快速上升`、可信度、受众和优先级等元数据，热门资源会在分类页中排序靠前。
