# 课程、Cookbook 与精选合集

这一页专门收“适合系统补课”的入口，不放零散热点文章。优先顺序是：官方课程、官方 cookbook、长期可维护的精选列表，最后才是社区灵感集合。

## 先收藏哪类学习资源

- 如果你刚起步，优先收官方课程和 beginner 系列仓库。
- 如果你已经能写 demo，下一层就看 cookbook 和带代码的实践仓库。
- 如果你只是想持续扫一遍生态变化，再补精选列表和长期观察清单。

## 重点补充：Microsoft AI Agents for Beginners

这次指定资源继续放在这一类里。它适合作为“官方课程型仓库”的标准样板，因为它不是单篇文章，而是一整套按课程组织的 agent 入门材料，也方便后续 fork、整理和内部二次导航。

## 补充工具型学习入口：Code Inspector

`Code Inspector` 不是传统课程，也不是平台型 AI 工具，但它很适合放在学习资源层长期收藏。

- 如果你经常接手前端项目、要从页面现象反查组件源码，先看这篇 [Code Inspector 学习资料](/docs/ai-directory/code-inspector)。
- 如果你只想先存入口，目录表里也已经保留了它的 GitHub 仓库和官方文档地址。
- 这类资源更像“前端工作流补课工具”，适合在正式教程之外作为第二层效率增强入口。
