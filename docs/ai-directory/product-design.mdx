# 产品与设计

这一类资源面向产品经理、设计师、用户研究和设计系统维护者，重点收能产出真实工作物的 AI 资源：调研摘要、需求材料、原型、界面、设计规范和反馈分析。

## 这类资源怎么用

- 先判断资源最终能产出什么交付物。
- 不把 prompt 小技巧当成产品或设计体系。
- 涉及研发交接时，优先选择能导出结构化规格、组件状态或验收材料的入口。
