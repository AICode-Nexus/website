# 数据与分析

这一类资源面向数据分析师、数据科学家、BI 用户和运营分析人员，重点收 Notebook、BI、数据清洗、可视化、实验分析和报告生成相关 AI 资源。

## 这类资源怎么用

- 优先选择能保留数据来源、分析步骤和复现记录的资源。
- 对自动洞察保持验证意识，不把生成结论直接当作事实。
- 与业务报告相关的资源，要能明确输入数据、分析逻辑和输出格式。
