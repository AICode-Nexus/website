# AI 编码工具与执行型 Agent

这一类资源解决的是“我现在该先存哪些产品官网、官方 Docs 和可直接研究的 agent 仓库”。判断顺序不是“哪个最火”，而是“哪一种入口最适合你当前的工作台和交付边界”。

## 这类资源怎么用

- 先看官网型入口，判断自己更偏平台、IDE 还是终端主线。
- 再看哪些工具有公开仓库，值得进一步研究或自托管。
- 真正要上手时不要停在官网页，直接回具体教程和 quick start。

## 推荐进入顺序

1. 如果还没定默认工作台，先看 `GitHub Copilot / Cursor / Claude Code` 这类主入口。
2. 如果你更关心执行链、开源性和自托管，再看 `OpenAI Codex / OpenHands / Cline / Aider`。
3. 如果看完目录后准备上手，下一步直接回 [AI 编程工具](/docs/tools) 进入具体 `quick-start`。
