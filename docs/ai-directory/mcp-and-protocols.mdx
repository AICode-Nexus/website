# MCP 与协议生态

这一页收的是 `Model Context Protocol` 及其周边生态，而不是单纯的“某个工具支持不支持 MCP”。目标是把协议文档、官方 SDK、参考实现和常用目录站放在一个稳定入口里。

## 先看哪一层

- 先看协议原点和官方 SDK，别一开始就刷社区 server 列表。
- 再看官方 servers 仓库和参考实现，建立对 server 形状的直觉。
- 最后再看 `Smithery`、`MCP.so` 这类社区目录站，作为发现层补充。

## 建议进入顺序

1. 先读 `Model Context Protocol` 官方文档。
2. 再按语言选择 `TypeScript SDK` 或 `Python SDK`。
3. 需要快速扫生态时，再看 `Smithery`、`MCP.so` 之类的目录站。
