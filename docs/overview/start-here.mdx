# 开始这里

这页不负责讲完整理论，也不负责让你背站点目录。它只做一件事：把你尽快送进第一条可执行主线，然后告诉你什么时候该回地图、方向页或索引页。

## 现在先做什么

- 如果你还没跑过任何主线，先去 [30 分钟上手](/docs/start/30-minute-quick-start)。
- 如果你准备做第一周练习，去 [7 天上手路线](/docs/workflows/playbooks/first-7-days-ai-coding)。
- 如果你现在就有真实任务，直接去 [AI 工作流实操手册](/docs/workflows/playbooks/workflow-playbook)。
- 如果你只想看别人怎么把工具接进交付链，去 [实战案例](/docs/case-studies)。
- 如果你想先看一个完整闭环，去 [Claude Code Bugfix Loop 案例](/docs/case-studies/claude-code-bugfix-loop)。

## 如果你今天只做一件事

- 想先把工具跑起来：去 [30 分钟上手](/docs/start/30-minute-quick-start)。
- 想按真实任务进入：去 [AI 工作流](/docs/workflows)。
- 想先选默认入口：去 [AI 编程工具](/docs/tools)。
- 想先知道自己卡在哪一环：去 [流程地图](/docs/start/journey-map)。

这四个入口已经够覆盖大多数第一次访问的场景。除非你已经明确知道自己缺的是方向判断、内容形态或旧分类词汇，否则先不要去更抽象的页。

## 按你当前状态进入

### 我还没跑过任何可执行路径

先去 [30 分钟上手](/docs/start/30-minute-quick-start)，然后回到 [学习路径](/docs/start/learning-paths) 看下一步。

### 我已经知道任务类型，只差一条稳定主线

直接进 [AI 工作流](/docs/workflows)，优先跑 `Runbook`，不要先在框架名之间打转。

### 我已经知道要做什么，但默认入口还没定

直接进 [AI 编程工具](/docs/tools)，优先找 `quick-start`，不要先看横向产品对比。

### 我已经在真实工作系统里推进 AI Code

直接进 [生态与集成](/docs/ecosystem)，优先解决 GitHub、Jira、CI、PR 和 review 怎么收口。

## 默认最短路径

1. [30 分钟上手](/docs/start/30-minute-quick-start)
2. [AI 工作流](/docs/workflows)
3. [AI 编程工具](/docs/tools)
4. [实战案例](/docs/case-studies)

如果上面四步里某一步开始让你觉得“我不是缺教程，我是缺阶段判断”，再回 [流程地图](/docs/start/journey-map)。

如果你已经知道阶段，但不知道该补哪类长期知识，再回 [知识方向总表](/docs/start/taxonomy)。

## 还不确定时回哪里

- 缺阶段判断：回 [流程地图](/docs/start/journey-map)。
- 缺方向判断：回 [知识方向总表](/docs/start/taxonomy)。
- 缺默认顺序：回 [学习路径](/docs/start/learning-paths)。
- 缺材料而不是判断：回 [资源中心](/docs/tools/resources)。
- 缺内容形态选择：回 [内容索引](/docs/content-index)。
