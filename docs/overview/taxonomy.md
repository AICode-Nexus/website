# AI Coding 知识体系总表

## 背景

AI coding 变化很快，如果只按工具名建站，内容会很快失控。这个站点统一按“赛道 + 内容形态 + 受众层级”来组织。

## 结论先行

- 主赛道负责稳定分类
- 内容形态负责决定写法
- 受众层级负责控制深度

## 适用场景

- 规划知识库目录
- 安排选题优先级
- 判断一篇文章应该写成教程、对比文还是趋势文

## 核心概念

### 主赛道

- 模型与 Agent
- IDE 与工具链
- 提示词与工作流
- 团队与交付

### 内容形态

- Daily Brief
- Comparison
- Playbook
- Guide
- Insight

### 受众层级

- Individual
- Mixed
- Advanced

## 推荐做法

1. 所有新文章先归类到主赛道
2. 再决定 `kind`
3. 最后决定面向个人工程师还是更进阶受众

## 常见错误

- 用产品名做一级目录
- 一篇文同时想做新闻、教程和评测
- 没有区分“新手入口”和“深度专题”
