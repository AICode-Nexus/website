# AI Code 流程地图

这张地图不负责替你选具体产品，也不负责替代知识方向。它只负责回答一个问题：

你现在处在哪个流程阶段，下一步最该补什么。

## 使用方式

1. 先找到你当前最卡的阶段。
2. 再看该阶段优先进入哪个知识方向。
3. 如果你需要的是材料或内容形态，再回资源中心或内容索引。

## 原始需求 {#raw-need}

你现在还在收口问题边界、目标用户、输入输出和风险。

优先进入：

- [开始这里](/docs/start/start-here)
- [开发范式与协作方式](/docs/development-modes)

优先进入：

- [工作流与交付](/docs/workflows)
