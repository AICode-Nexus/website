# AI Code 教学视频库

这个页面已经接入“**手动触发同步、构建期写入本地数据**”的抓取流程：脚本读取稳定的种子视频列表，抓取 B 站公开视频详情页里的标题、UP 主、发布时间和 canonical 链接，再把结果固化为站内 JSON，供首页模块、专题页和知识文档引用。

最近一次同步：**{lastSyncedAt}**

## 当前同步策略

- 输入源是 `src/data/teachingVideos.seed.json` 里的稳定视频种子项。
- 通过 `npm run sync:teaching-videos` 抓取公开视频详情页，不依赖搜索页、推荐页或未公开接口。
- 输出写入 `src/data/teachingVideos.generated.json`，站点页面只消费本地生成结果。
- 这意味着抓取发生在“人工触发同步”阶段，而不是在浏览器运行时或 Docusaurus 构建时临时请求 B 站。

## 当前抓取字段

- 标题
- UP 主
- 发布时间
- canonical 视频链接
- 页面简介
- 页面关键词
- 系列课集数（能从公开页面识别时）
- 缩略图链接
- 站内标签与编辑摘要

## 如何更新数据

```bash
npm run sync:teaching-videos
npm run build
```

## 设计边界

- 站点仍然不追求“自动抓全站最新视频”，而是维护一份可验证、可复用的精选种子清单。
- 如果后续要补更多平台，优先继续沿用“公开详情页抓取 + 本地生成文件”的方式，而不是把实时抓取塞进页面运行时。
