# AI Code 教学视频库

这个页面不再是手工精选列表，而是一个<strong>近 90 天、{teachingVideoCatalogSync.intervalLabel} 自动同步一次的视频中心</strong>。目录只保留符合教学内容识别、时间窗口、字段完整性和质量阈值的公开视频，并同时给出 `videoCount` 与 `courseCount` 两个口径。

最近一次同步：**{lastSyncedAt}**；自动同步周期：**{teachingVideoCatalogSync.intervalLabel}**

## 当前目录规则

- 只展示 `windowStart` 到 `windowEnd` 时间窗内的公开视频。
- 同一语言的重复镜像会做 canonical 去重，并保留 `alternateUrls`。
- 系列教程会拆成可播放视频条目，同时聚合课程层数据。
- 页面运行时不做任何外部抓取，所有分类、打标、排序都在同步脚本阶段完成。

## 同步入口

```bash
npm run sync:teaching-videos
npm run check:teaching-videos
npm run build
```

自动同步策略：**{teachingVideoCatalogSync.description}**

## 当前页面内容

下面的目录页由本地生成的数据直接渲染，支持按平台、主题、语言和时间窗口筛选。页面本身不请求外部站点，所有清洗、聚合和分类都在同步脚本阶段完成。

## 维护边界

- 这个页面优先服务“知识入口”和“视频目录索引”，不是文章内容本体。
- 质量门槛、标签规则和时间窗策略应在同步脚本与测试里调整，而不是在页面运行时临时修补。
- 如果后续扩平台，优先继续沿用“同步脚本生成本地数据”的方式，避免把实时抓取塞进构建或浏览器运行时。
