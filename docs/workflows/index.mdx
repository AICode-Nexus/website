# AI 工作流

这一层不再只是一篇“工作流总览”。现在它拆成三种对象：

- 工作流模式：回答任务应该走哪条交付链。
- 官方/主线工作流框架：回答团队要不要引入完整框架骨架。
- 社区工作流框架：回答日常 agent 协作能不能再加一层方法论。

## 先怎么用这一层

如果你还没固定默认交付链，先从工作流模式开始。

如果你已经知道自己要 `spec-first`、`issue -> PR` 还是 `terminal-first`，但团队总在边界和 handoff 上出问题，再看框架层。

如果你已经高频使用 coding agents，想把 brainstorming、worktree、plan、TDD 和 review 变成日常习惯，再看社区工作流框架。
